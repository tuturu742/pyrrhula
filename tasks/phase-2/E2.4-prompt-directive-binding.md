# E2.4 — Prompt-directive binding (banded rendering)

**Phase:** 2 · **Track:** E · **Est:** 3d · **Status:** done
**Depends on:** E2.3 (done) · **Blocks:** —
**Plan refs:** §8.2

## Goal
The `prompt_directive` binding for low-stakes axes: render an axis value into a banded
natural-language instruction. Band the values, don't inject a number — models follow "you
speak rarely, and only when you have something substantive to add" far more reliably than
"talkativeness: 20/100". Deliberately small; do not over-engineer.

## Subtasks
- [x] Band renderer in `core/behavior/directives.py`: value → band lookup → template string.
      Band boundaries and template text are **pack data** on the axis definition, not code.
- [x] Assembler integration: rendered directives enter the persona/system section of the
      layout (C1.4's *stable* region — directive text changes only when the profile version
      does, preserving the prompt-cache prefix). `assemble()` gained an optional
      `behavior_directives_text` kwarg (additive, defaulted — INV-2 only freezes
      `viewer`/`phase`); `core.process.live_session` resolves it via
      `render_directives_for_profile` before calling `assemble()`.
- [x] Validation: bands must cover the full range with no gaps or overlaps; checked at pack
      load alongside E2.3's rules — `validate_prompt_directive_bindings`, called from
      `create_axis_definition` right after `validate_axis_definition`.
- [x] Restriction: the binding is accepted only on `stakes: low` axes — a high-stakes axis
      with *only* a prompt binding is already rejected by E2.3; this task enforces the
      converse (a directive binding on a high-stakes axis renders *in addition to* the gate,
      never instead of it). No extra code needed: E2.3's stakes:high⇒gate rule already
      guarantees the gate is present; `secret_disclosure_propensity`'s fixture carries
      both a gate and a prompt_directive binding to prove the combination actually renders.

## Acceptance criteria
- A value of 20 on a 0–100 axis with bands at 0–20/21–40/… renders the first band's text;
  band edges are inclusive-exclusive and total (no value maps to nothing).
  → `test_band_rendering_is_total_and_boundary_exact`
- No numeric axis value ever appears in the rendered context — the directive is words only.
  → `test_rendered_directive_contains_no_raw_axis_number`
- Changing an unrelated volatile part of context does not change the rendered directive
  bytes (cache-prefix stability).
  → `test_directive_bytes_stable_across_turns_for_same_profile_version`

## Design decisions
- **Bands as pack data, not code**, because band phrasing is domain voice: "you wave things
  through" (swdev `review_strictness`) and "you speak in riddles" (RPG oracle) are content
  decisions, and packs may not require core changes to make them (INV-9).
