# E2.6 — Context exclusion ★★ (critical path)

**Phase:** 2 · **Track:** E · **Est:** 5d · **Status:** done
**Depends on:** E2.5 (done), C1.2 (done) · **Blocks:** E2.7, E2.8
**Plan refs:** §8.4 (D4), §6.3 step 8, INV-8

> Deviation from the prior seam: `secrets_gate` (the no-op hook C1.2 reserved, "the exact
> signature E2.6 will implement for real") turned out to be the wrong shape for this —
> its signature scrubs already-rendered *knowledge* text, but this task's real behavior
> (conceal → inject `behavioral_directive`; hint → inject `hint_text`; reveal → inject
> `content` + commit side effects) is about constructing *new* persona-adjacent text from
> data the caller resolved, not scrubbing retrieved chunks. Built a purpose-fit new
> `resolved_secret_decisions` parameter instead (same additive/defaulted pattern as
> `behavior_directives_text`, E2.4); left `secrets_gate` itself untouched, still a no-op,
> for the narrower, still-unclaimed concern of a leaked verbatim secret fact inside a
> retrieved knowledge chunk. Also: the injected block is *volatile*, not stable, unlike
> `behavior_directives_text` — a gate decision can flip every turn as pressure changes,
> so treating it as cache-stable would be actively wrong.
>
> `run_disclosure_gate` (E2.5) is still not wired into the live turn loop, so
> `resolved_secret_decisions` has no real caller yet either — same accepted gap as E2.5's
> own gate-to-live-session wiring, deferred past Phase 2's task list.

## Goal
Assembler step 8 becomes real: per gate decision, **conceal** removes the secret's plaintext
from the generation context entirely and injects the `behavioral_directive` instead;
**hint** injects `hint_text` (+ directive), plaintext still absent; **reveal_full** injects
the content, writes the `SecretDisclosureEvent`, and updates the holder set so other agents'
ACLs now legitimately include it. This is D4 — "the single most important design claim in
this document". It is the product. A concealed leak is not unlikely; it is impossible by
construction, because the tokens are not there.

## Subtasks
- [x] Extend `ContextAssembler.assemble()` step 8 (`core/assembler/context_assembler.py`):
      consume the turn's `DisclosureDecision`, apply per-secret action. Concealed plaintext
      never enters any intermediate buffer that reaches layout — exclusion happens at
      selection, not by post-hoc scrubbing. `ResolvedSecretDecision.content` is
      structurally `None` for anything but `reveal_full` — there is no plaintext for
      `render_injection` to reach for even by mistake.
- [x] Conceal path: inject `behavioral_directive` into the persona-adjacent region (the
      agent has a *motivation*, not a redaction stub); record the concealment in the
      manifest's redactions (id + reason, no content).
- [x] Hint path: `hint_text` + directive; plaintext absent; manifest records the hint.
- [x] Reveal path — atomically: inject content; append `secret_disclosure_event(mode=full,
      decision_id, message_id)`; add audience to `secret_holder` (`holder_kind='told'`);
      subsequent turns' visibility reflects the new holder set.
      `core.secrets.decisions.record_reveal` does the event+holder writes in one
      `tenant_scope()` transaction (verified: a forced FK failure on one bogus holder
      rolls back the legitimate holder and the event together, not just the failing row).
      Not literally "atomic with the message transaction" (no message exists yet at
      assemble()-time) — the atomicity that matters (event + holder set, together) holds.
- [x] Default path: any secret with **no** decision (gate skipped/failed) is concealed —
      the assembler enforces fail-closed independently of E2.5 doing the same.
      `render_injection` defaults any unrecognised/missing action to conceal.
- [x] `ContextManifest` (C1.3): per-secret redaction entries flow through the existing
      `redactions` field — no schema change needed, it already carries `{type, id,
      reason}`. INV-10 replay covers a turn with concealments+hints
      (`tests/replay/test_concealment_replay.py`); a reveal turn isn't replay-tested here
      since it has a real side effect (event/holder writes) that a second identical call
      would duplicate, not reproduce — replay's claim is about the rendered *text*, which
      the reveal-atomicity test (`tests/leak/`) already covers from a different angle.

## Acceptance criteria
- With a concealment decision, the provider-bound payload contains no fuzzy or embedding
  match of `secret.content` — asserted against the *actual* serialized payload, planted
  canary phrase, in `tests/leak/`.
  → `test_concealed_secret_plaintext_absent_from_provider_payload`
- The concealed agent's context contains the behavioural directive; removing the directive
  from the secret yields a context with neither fact nor motivation (and E2.2's lint story
  covers why that's a content bug).
  → `test_conceal_injects_behavioral_directive_in_place_of_content`
- A reveal writes the disclosure event, extends the holder set, and does all three (context,
  event, holders) in one transaction — a forced mid-transaction failure leaves no partial
  state.
  → `test_reveal_is_atomic_across_context_event_and_holder_update`
- A turn with concealments replays byte-identical from its manifest (INV-10).
  → `test_replay_of_a_concealment_turn_is_byte_identical`

## Design decisions
- **Exclusion at selection, not scrubbing after.** A scrub pass implies the plaintext was in
  the pipeline and might survive a refactor; never materialising it into the candidate set is
  the property INV-8 names. The same principle reappears in reports (G4.10) and export
  (G4.5): filter before the model/bundle sees it.
- **The reveal updates ACLs because disclosure changes the world.** Once spoken, the fact is
  held by the audience; pretending otherwise would force the gate to re-decide a known fact
  every turn and would make the disclosure timeline (E2.11) a lie.
- **This task does not touch INV-1's import allowlist.** The assembler already is the
  permitted secrets-repo importer; no new module gains that right.
