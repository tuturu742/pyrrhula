# G4.4 — Human-in-place-of-agent (req 10)

**Phase:** 4 · **Track:** G · **Est:** 4d · **Status:** done
**Depends on:** B1.7 · **Blocks:** —
**Plan refs:** §5.2 (`generate_as`), §12.7, req 10

## Goal
A human replies in place of any agent — verbatim, or passed through an AI voice-conformance
rewrite — with the override never hidden: `was_human_override` is recorded and surfaced in
the UI. The director speaking as the innkeeper and the manager stepping in for a stuck
engineer agent are the same mechanism.

## Subtasks
- [x] `mode: generate_as` turn path: a permitted human submits a message attributed to an
      agent actor; permission-checked (`agent:speak_as`) via `PermissionService`, per
      workspace role config.
- [x] Verbatim mode: text lands as the agent's message, `was_human_override = true`,
      `rewrite_applied = false`.
- [x] Voice-conformance mode: the text is rewritten into the agent's persona voice
      (`purpose='rewrite'`, egress policy applies); both original and rewrite are stored;
      the human confirms the rewrite before it posts; `rewrite_applied = true`.
- [x] Downstream integrity: an override message flows through the same pipeline as a
      generated one — leak check (E2.7) still runs (a human can accidentally leak a
      concealed secret's content; the tripwire applies), scheduler advances identically.
      → The *check* is E2.7's; the *response ladder* deliberately differs. There is
      nothing to regenerate when the words are a person's, so a leaking override is
      **refused** (no message written, overseer alerted) rather than replaced with a bland
      fallback posted under the agent's name — which would be a second, worse override on
      top of the first. Reasoned in `core/agents/override.py`'s docstring.
- [x] UI: override badge on the message (visible per workspace policy — the overseer always
      sees it; whether participants do is a workspace setting with the honest default on).

## Acceptance criteria
- An unauthorized principal cannot speak as an agent; an authorized one produces a message
  the turn scheduler treats as that agent's turn.
  → `test_generate_as_is_permission_gated_and_advances_the_agents_turn`
- A rewrite posts only after human confirmation; the stored pair (original, rewrite) is
  retrievable by the overseer.
  → `test_rewrite_requires_confirmation_and_preserves_the_original`
- `was_human_override` is never false for an override (asserted through both modes) and
  renders in the session view for the overseer.
  → `test_override_flag_recorded_and_surfaced`
- An override containing a concealed secret's plaintext trips E2.7's leak check.
  → `test_human_override_still_passes_the_leak_check`
