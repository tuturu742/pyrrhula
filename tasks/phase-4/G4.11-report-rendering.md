# G4.11 — Report rendering (req 26)

**Phase:** 4 · **Track:** G · **Est:** 4d · **Status:** done (partial — see scope note)
**Depends on:** G4.10 · **Blocks:** —
**Plan refs:** §11.5, req 26

> **Scope note.**
> 1. **PDF is implemented but cannot run here.** WeasyPrint needs pango, cairo, and
>    gobject; this environment has none of them (`ldconfig -p` finds zero). `render_pdf`
>    raises a named `PdfRenderingUnavailableError` rather than emitting something
>    PDF-shaped — a renderer that quietly produced HTML under a `.pdf` name would be a file
>    that opens wrong on someone's machine days later with no clue why. The
>    identical-content criterion is proven across **Markdown, HTML, and EPUB** by
>    extraction-based comparison; the PDF arm of that test runs whenever WeasyPrint is
>    importable and asserts the unavailability error otherwise. HTML is what WeasyPrint
>    consumes, so the format the PDF would be made *from* is fully covered.
> 2. **No report UI.** The endpoints (generate, read, review, render, download) are real
>    and tested; no React surface displays a report or its artifacts.

## Goal
Human-readable, shareable outputs from `report.content_md`: Markdown → PDF (WeasyPrint) and
EPUB, with redaction stubs visibly preserved in every format. The rendered artifact is a
faithful presentation of the reviewed report object — rendering adds format, never content.

## Subtasks
- [x] Renderer worker step: Markdown → styled PDF via WeasyPrint (print stylesheet;
      overlay-resolved labels in headings) and → EPUB; artifacts stored via `BlobStore`,
      referenced from `report.artifacts`. → **PDF unrunnable here, see scope note**;
      Markdown, HTML, and EPUB are real and tested.
- [x] Redaction stubs survive rendering distinctly (a styled "[not visible to you]" block,
      not silently absorbed text) in Markdown, PDF, and EPUB alike.
- [x] Optional review gate honored: a template can require `reviewed_by` before artifacts
      are downloadable; unreviewed reports render with a draft watermark.
- [x] Download endpoints permission-checked as report reads (the report was generated *for*
      a principal; another principal doesn't inherit it).

## Acceptance criteria
- The same report renders to MD, PDF, and EPUB with identical text content and visible
  redaction stubs in each (extraction-based comparison).
  → `test_all_formats_carry_identical_content_and_visible_stubs`
- A report generated for principal A is not downloadable by principal B without an
  overseer-grade permission.
  → `test_report_artifacts_are_scoped_to_their_target_principal`
- A review-required template blocks artifact download until `reviewed_by` is set.
  → `test_review_gate_blocks_unreviewed_downloads`
