# T0.3 — Ports with trivial v1 implementations

**Phase:** 0 · **Track:** Infra · **Est:** 7d · **Status:** done
**Depends on:** T0.2 · **Blocks:** T0.8, A-track, B-track, C-track
**Plan refs:** §14.3 (D11), §13.6, §13.9 (D14)

> Status reconciled during the Phase-0/1A review: implemented and committed earlier. All
> nine ports exist in `core/ports/` (Permission, Identity, TenantRouter, VectorStore,
> ModelProvider, JobQueue, BlobStore, Encryptor, Moderation) with trivial v1 adapters in
> `packages/adapters/` (14 adapter contract tests). D14 egress lives inside `ModelProvider`
> (`check_egress`, runs before the provider SDK loads); `VectorStore.search` has defaultless
> `scope_keys`/`class_` (INV-4). The checkboxes just hadn't been ticked.

## Goal
Every cross-cutting concern behind an interface with a deliberately trivial v1
implementation, so SSO / fine-grained RBAC / residency / Qdrant / Temporal / KMS become
adapter swaps, not rewrites.

## Subtasks
- [x] `PermissionService.check(principal, action, resource) -> bool` — v1: `role_permission`
      lookup. Raise on unknown action strings (typo defence).
- [x] `IdentityProvider` — v1: local password (argon2) + session issuance.
- [x] `TenantRouter.dsn_for(tenant) -> DSN` — v1: single DSN; reads `tenant.region` and
      `isolation_mode` fields even though it ignores them.
- [x] `VectorStore` — v1: pgvector. Signature requires `tenant_id`, `scope_keys` (defaultless)
      and `class_`; filter applied as SQL predicate (INV-4 pushdown).
- [x] `ModelProvider` — LiteLLM wrapper implementing `generate` (streaming),
      `generate_structured(schema)`, `count_tokens`, `capabilities(model)`.
- [x] **Egress policy check inside `ModelProvider`** (D14): consult
      `tenant.settings.egress_policy[purpose]` before dispatch; `purpose` is a required
      argument; violation raises a typed error. Default policy: all purposes allowed.
- [x] `JobQueue` — v1: Postgres table + `FOR UPDATE SKIP LOCKED` polling worker loop.
- [x] `BlobStore` — v1: local filesystem; S3 adapter interface-ready.
- [x] `Encryptor` — v1: identity function, used on `secret.content` write path placeholder.
- [x] `ModerationProvider` — v1: no-op allow-all with hook points defined.
- [x] Adapters live in `packages/adapters/`; core imports only the port protocols.

## Acceptance criteria
- Each port has a protocol type, at least one adapter, and a contract test the adapter passes.
- A `ModelProvider.generate(..., purpose="generation")` call against a tenant whose policy
  says `generation: [local]` and a cloud profile fails with the typed egress error — test.
- `VectorStore.search` cannot be called without `scope_keys` (mypy + runtime).

## Files / modules
`packages/core/ports/*.py`, `packages/adapters/{vector,models,identity,queue,moderation}/`.

## Constraints
- Ports are boring on purpose. Do not add features to a port that its Phase-5 replacement
  wouldn't share.
