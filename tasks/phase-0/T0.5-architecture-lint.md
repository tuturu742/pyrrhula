## Goal
The import-graph rule that makes the Context Assembler the only path from stored text to a
model: "the single highest-value test in the repository."

## Subtasks
- [x] Import-linter (or equivalent) contract: only `packages/core/assembler/` and
      `packages/core/overseer/` may import `packages/core/knowledge/repo*` and
      `packages/core/secrets/repo*`.
- [x] Second contract: `packs/` may import nothing from `packages/core/` (packs are content).
- [x] Third contract: nothing outside `packages/core/tenancy/` imports the raw sessionmaker.
- [x] CI job, merge-blocking; failure message explains *why* (link to CLAUDE.md rule 2).
- [x] Repo/module stubs created as needed so the contracts bind real paths from day one.

## Acceptance criteria
- Adding `from core.knowledge.repo import ...` to any other module fails CI (demonstrated in
  a scratch branch).
- A `.py` file in `packs/` importing `core.*` fails CI.
